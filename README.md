## Project Overview

College students receive announcements about examinations, assignments, events, holidays, fees, placements, and other academic activities. Important information can be missed when announcements are scattered across different channels.

The Student Announcement Intelligence System demonstrates how a trained Machine Learning model can automatically classify announcement text and help students identify important information.

The application uses a TF-IDF text vectorizer and a Logistic Regression classifier, with a Streamlit interface for interactive predictions.

## Problem Statement

Students often need to identify the category, urgency, and required action from college announcements.

This project aims to:
- Automatically predict an announcement category from its text.
- Estimate priority using transparent rules.
- Suggest a relevant next action.
- Display model predictions in a simple web interface.

## Key Features

- **Text Classification:** Predicts an announcement category using a trained ML model.
- **Priority Estimation:** Assigns High, Medium, or Low priority using documented rules.
- **Action Suggestions:** Provides a helpful next step based on the announcement.
- **Interactive Interface:** Allows users to paste announcement text into a Streamlit application.
- **Prediction Confidence:** Displays model probabilities when supported by the trained classifier.
- **Evaluation Reports:** Records model evaluation metrics from held-out test data.
- **Announcement History:** Supports reviewing previous predictions if history storage is enabled in the application.

## Dataset

The prototype uses a labelled CSV dataset of sample college announcements.

Expected columns:

| Column | Description |
|---|---|
| `announcement_text` | Text of the college announcement |
| `category` | Correct category label for training |

Supported example categories:

- `EXAM`
- `ASSIGNMENT`
- `EVENT`
- `HOLIDAY`
- `PLACEMENT`
- `FEE`
- `GENERAL`

The sample dataset is intended for demonstration and learning. It is not an official college dataset. Model performance depends on the quantity, diversity, and quality of the labelled examples.

## Machine Learning Model

### TF-IDF Vectorization

TF-IDF converts announcement text into numerical features that can be processed by a Machine Learning algorithm.

### Logistic Regression

Logistic Regression learns relationships between the TF-IDF features and the labelled announcement categories.

### Model Training

Run the training script to:
1. Load and validate the dataset.
2. Remove invalid rows.
3. Split data into training and test sets.
4. Fit the TF-IDF and Logistic Regression pipeline on training data.
5. Evaluate predictions on held-out test data.
6. Save the trained pipeline for reuse.

The test set must not be used to train the model.

## Evaluation

The training workflow should report:

- Accuracy
- Macro-F1 score
- Weighted-F1 score
- Per-class precision and recall
- Classification report
- Confusion matrix, if implemented

Actual results should be taken from the output of `train_model.py` or the generated reports. Performance numbers are not included here because they must be verified from an actual training run.

## Run the Application

### Step 1: Train the model

```bash
python train_model.py
```

This should train and save the model and generate evaluation results if the dataset and dependencies are available.

### Step 2: Start Streamlit

```bash
streamlit run app.py
```

Open the local URL displayed in the terminal, usually `http://localhost:8501`.

If the trained model is missing, run the training script before starting predictions.

## Limitations

- Predictions depend on the quality and coverage of the sample training dataset.
- Model confidence does not guarantee that a prediction is correct.
- Priority estimation uses separate rules and may not understand every deadline or context.
- The prototype is not an official college notification system.
- The current language support depends on the training data and preprocessing implementation.
- Local execution does not mean that the application is deployed publicly.

- Improve deadline and date extraction.
